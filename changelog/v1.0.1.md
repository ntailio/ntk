# ntk v1.0.1

A bug fix release for the Unix socket input.

## Fixes

- **Stopping `produce --in unix:` no longer loses messages.** On ctrl-c or SIGTERM, ntk is meant to produce every message already waiting on the socket before it exits. A timing issue could make it stop reading too early, so messages that had already been sent to the socket were dropped. It now reads the whole queue every time.

## Install

- **Binaries** for Linux (amd64, arm64, armv7), macOS (Intel and Apple silicon), Windows (amd64, arm64) and FreeBSD (amd64) are attached below, with a checksums file.
- **Docker**: `ghcr.io/ntailio/ntk:v1.0.1`
- **Go**: `go install github.com/ntailio/ntk/cmd/ntk@v1.0.1`
